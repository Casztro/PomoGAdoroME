# PomoGAdoroME

Um relógio Pomodoro para Windows, desenvolvido para ajudar a organizar períodos de foco e pausas durante as atividades do dia a dia.

## Sobre o projeto

O PomoGAdoroME é uma aplicação de desktop para Windows baseada na técnica Pomodoro, um método de gestão do tempo que alterna períodos de concentração com intervalos de descanso.

## Plataforma

- Windows
